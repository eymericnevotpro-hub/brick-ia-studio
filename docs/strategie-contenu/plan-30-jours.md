# Plan 30 jours — 90 vidéos, jour par jour

Le plan concret. Chaque ligne est une vidéo à tourner : format, pilier, titre.
Codes formats : voir [`style-et-formats.md`](./style-et-formats.md).

**Rythme :** 3 vidéos/jour → TikTok (11h / 17h / 20h30), les 2 meilleures en Reels
(12h30 / 19h), les 2 mêmes en Shorts YouTube. Une vidéo tournée = 3 plateformes.

**Répartition sur 90 vidéos :** Réseaux 33 · Tuto IA 22 · Veille IA 12 · Tech 9 · Perso 14

## Ce qu'il faut faire tous les jours (non négociable)

| Quand | Quoi | Durée |
|---|---|---|
| Matin | Publier les 3 vidéos programmées · 2 stories | 15 min |
| Après chaque publi | Répondre à **tous** les commentaires dans l'heure | 20 min |
| Soir | 2 stories (coulisses + question) · noter 3 idées | 15 min |
| Lundi | Revue stats · écrire les variantes des 3 tops | 30 min |
| Lundi + jeudi | **Tournage batch** (4 h + 3 h → 20 vidéos) | 7 h/sem |
| Dimanche | Écrire les 21 titres de la semaine suivante | 1 h |

---

## Les 3 règles de pilotage

1. **Un top se double.** Toute vidéo > 100k vues génère 2 variantes dans le batch suivant
   (angle 2, format différent, version longue). Le sujet est validé, tu recharges.
2. **Un flop se diagnostique.** Rétention 3 s basse → c'est le hook, garde le sujet et
   réécris. Rétention correcte mais peu de partages → c'est le sujet, abandonne-le.
3. **Un créneau reste libre.** Si une actu IA majeure tombe, elle remplace la vidéo la
   moins prioritaire du jour. La réactivité bat le planning.

> rétention à 3 s et le taux de vues non-abonnés.
